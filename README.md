# MovieBot

Telegram-бот для поиска фильмов по названию и жанру, просмотра подборок и истории запросов

Учебный проект на Python. Бот обращается к внешнему API Кинопоиска и сохраняет историю отдельно для каждого Telegram-чата в SQLite

## Возможности

| Команда | Что делает |
| --- | --- |
| `/start` | Запускает диалог |
| `/help` | Показывает доступные команды |
| `/search` | Ищет фильмы по названию |
| `/genre` | Предлагает поиск по жанру |
| `/top` | Открывает подборку топ-250 |
| `/random` | Подбирает фильм через случайное поисковое слово |
| `/history` | Показывает последние десять записей истории |

Карточки содержат сведения о фильме, постер и ссылку на Кинопоиск. Для списков предусмотрены кнопки переключения

## Стек

Python · pyTelegramBotAPI · requests · Peewee · SQLite · Pydantic Settings

## Структура

| Файл | Назначение |
| --- | --- |
| `main.py` | Точка входа и запуск polling |
| `handlers.py` | Обработчики команд и кнопок Telegram |
| `api_client.py` | HTTP-запросы к внешнему API |
| `models.py` | Модель истории и подключение SQLite |
| `settings.py` | Настройки и чтение переменных окружения |

## Локальный запуск

Код использует синтаксис Python 3.10 и новее. Для запуска нужен интерпретатор, совместимый также с закреплёнными версиями зависимостей; минимальная поддерживаемая всем набором пакетов версия отдельно не проверялась

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
cp .env.example .env
```

Получи токен у [BotFather](https://t.me/BotFather) и ключ у [провайдера API](https://kinopoiskapiunofficial.tech/). Заполни `BOT_TOKEN` и `API_KEY` в локальном `.env`, затем запусти:

```bash
python main.py
```

Бот использует polling. Не запускай несколько экземпляров с одним токеном. При первом импорте моделей создаётся локальная `history.db`; готовая история пользователей в репозиторий не входит

## Ограничения учебной версии

- Состояние навигации хранится в памяти процесса и теряется при перезапуске
- HTTP-клиенту нужны явные таймауты и обработка сетевых исключений
- Покрытие автоматическими тестами в этой версии не подготовлено
- Доступность отдельных методов внешнего API зависит от провайдера и тарифа ключа

Следующие улучшения: тесты обработчиков и клиента, таймауты запросов и более устойчивое хранение состояния диалога
